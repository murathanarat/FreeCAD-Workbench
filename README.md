# Ahsap FreeCAD Workbench

Ahsap Workbench, FreeCAD için geliştirilmiş özel bir çalışma tezgahıdır. Ahşap yapı tasarımı ve analiz süreçlerini kolaylaştırmak amacıyla geliştirilmiştir.

## Özellikler

* Özel FreeCAD Workbench entegrasyonu
* Kat (Floor) ve kroki (Sketch) oluşturma araçları
* Ahşap malzeme kütüphanesi yönetimi
* Malzeme özelliklerinin (fmk, ft0k, ft90k, fc0k, fc90k, fvk, E0ort, E005, E90ort, Gort, pk, port) tanımlanması
* PySide tabanlı kullanıcı arayüzü
* CSV/TXT tabanlı malzeme verisi okuma
* FreeCAD belge yapısı içerisinde proje organizasyonu
* Özel komutlar ve araç çubukları

## Amaç

Bu proje, FreeCAD üzerinde ahşap yapı elemanlarının modellenmesi, malzeme yönetimi ve ileride yapılacak yapısal analiz çalışmalarına temel oluşturmak amacıyla geliştirilmektedir.

## Kullanılan Teknolojiler

* Python
* FreeCAD API
* PySide2
* Pandas
* Qt Designer

## Durum

Proje aktif geliştirme aşamasındadır. Yeni özellikler ve iyileştirmeler eklenmeye devam edilmektedir.
